# Vishwa Innovates

Recruiter-focused portfolio website for Vishwa Perera, built with Gatsby, React, TypeScript, and SCSS modules.

## Local development

```bash
npm run develop
```

## Available scripts

```bash
npm run develop
npm run build
npm run serve
npm run clean
npm run typecheck
```

## Project notes

- Single-page portfolio with sections for overview, experience, selected work, and contact.
- Structured content lives in `src/content/portfolio.ts`.
- Global styling is handled with SCSS modules plus shared tokens in `src/styles/global.scss`.
